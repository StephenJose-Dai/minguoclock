# 民国时钟 MinguoClock

Android 民国纪年锁屏 + 桌面小组件。

- **锁屏**：熄屏后亮起时显示 `民國115年11月2日 星期一` + 农历 + 时分秒（数字滚动动画），6 套流动渐变主题，上滑解锁（有密码/指纹时照常走系统验证），显示电量和下一个闹钟。
- **桌面小组件**：时分秒由系统 TextClock 驱动（每秒走、省电），民国日期和农历每天零点准时刷新；白字 / 深色字 / 卡片三种样式，可自由缩放，点按打开系统闹钟。
- **设置**：繁體/简体、阿拉伯数字/中文数字（民國一百一十五年）、是否显示秒、主题实时预览、权限一键检查。
- 无联网、无统计、无广告，农历用的是 Android 系统自带 ICU 历法。

要求 Android 8.0 (API 26) 及以上。

## 编译

**方式一：GitHub Actions（不用装环境）**
把整个目录推到你自己的 GitHub 仓库（私有也行），Actions 会自动编译，在该次运行的 Artifacts 里下载 `MinguoClock-apk`，解压得到 `app-release.apk`。

**方式二：本地**
用 Android Studio 打开本目录，或命令行（需 JDK 17 + Android SDK）：

```bash
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

> release 包用 debug 密钥签名，方便自用直接安装。每台机器/每次 CI 生成的 debug 密钥不同，**换了编译环境后升级安装会提示签名冲突**，需先卸载旧版。想长期稳定升级，可以自己生成一个 keystore 配到 `app/build.gradle.kts` 的 `signingConfigs` 里。

## 小米 / HyperOS 设置（必须）

安装后打开 App → 打开「启用民国锁屏」，然后按「权限检查」里的按钮逐项开启：

1. **显示在其他应用上层** —— 没有它锁屏弹不出来
2. **后台弹出界面** + **锁屏显示** —— 应用信息 → 权限管理 → 其他权限（HyperOS 特有，缺一不可）
3. **自启动** —— 开机后自动恢复
4. **省电策略：无限制** / 忽略电池优化 —— 防止服务被杀
5. 最近任务里把「民国时钟」卡片下拉**加锁**

全部开启后点「预览锁屏效果」看看，再锁屏实测一次。

## 工作原理与限制

Android 不允许第三方应用真正替换系统锁屏。本应用的做法和市面上锁屏 App 一样：

- 常驻一个前台服务（通知栏会有一条静默通知，可在系统通知设置里把它隐藏），监听熄屏；
- 熄屏瞬间把锁屏界面盖在系统锁屏**之上**，亮屏时你先看到的就是它；
- 上滑后调用系统 `requestDismissKeyguard`：无密码直接进桌面，有密码/指纹则弹出系统验证；
- 直接用指纹/人脸解锁系统锁屏时，本界面会跟着自动关闭。

因此：系统锁屏的安全性不受影响；但通知列表、锁屏快捷方式（相机、手电）在本界面上看不到，需要上滑后在系统锁屏上操作。通话中贴脸熄屏不会弹出本锁屏。

## 文件结构

```
app/src/main/java/club/daishenghui/minguo/
├── RocCalendar.kt    民国纪年、中文数字、农历干支生肖格式化

├── LockActivity.kt   锁屏界面（上滑解锁）
├── LockService.kt    前台服务，监听熄屏拉起锁屏
├── ClockWidget.kt    桌面小组件 + 零点刷新
├── BootReceiver.kt   开机/更新后恢复
├── MainActivity.kt   设置界面
└── Prefs.kt          设置存储
```
