# 民国纪年 MinguoClock v3.16

Android 民国纪年锁屏 + 桌面小组件 + 通知栏民国日期。作者：StephenJose_Dai

## 功能一览

**锁屏**
- 两种模式：
  - **完全替代**：系统锁屏设为「无」后，民国锁屏是唯一锁屏，亮屏到解锁全程看不到系统时间；悬浮窗实现，Home / 返回 / 最近任务都关不掉；可设图案或 4–8 位数字密码（连错 5 次锁 30 秒；必须先关闭系统锁屏才能设置）。
  - **保留系统密码**：盖在系统锁屏上，指纹/人脸直接解锁；上滑会出现系统密码界面。
- 所有元素都能**拖动位置、双指缩放、单独设置字体/字号/粗细、隐藏**：时间、日期、农历、天气、天气建议、名言、签名。拖动不会弹出参数面板，单击元素才弹出。
- 可**添加任意图片**（如国旗，保留透明背景），拖到任意位置、调整大小。
- 签名不限字数，**单行、字号固定**，超长时向左跑马灯滚动。
- 名言：内置 130 余句经典名言与「一言」在线名言混合，不显示作者；每次熄屏换一句，亮屏期间每 30 分钟换一句。
- 壁纸：渐变主题 / 自选图片 / 必应壁纸（在最近十几天的必应壁纸里轮换：每次熄屏换一张，亮屏期间每 30 分钟换一张；按屏幕分辨率选竖版或 UHD，图片预下载缓存，切换不用等网络）。
- 内置字体：文楷（LXGW WenKai）、圆体（jf open 粉圆）、芫荽、Orbitron、Share Tech Mono，也可导入 TTF/OTF。
- 系统状态栏原样显示；适配刘海、挖孔、灵动岛；紧急呼叫入口。

**天气**（全部免注册、免申请）
- 刷新频率（兼顾实时和省电）：亮屏时天气超过 30 分钟才刷新、位置超过 30 分钟才重新定位；熄屏时每小时刷新一次（系统休眠时顺延）。定位参考手机自带天气：网络定位（Wi-Fi + 基站）优先，精度 100 米内直接用；不够准时再用 GPS 补充、取更准的，最多 15 秒结束；另外被动接收其它应用（导航、地图等）拿到的位置，移动超过 1 公里自动更新天气，不额外耗电；每次只取一次位置，取到即停。开着「自动定位」时，打开 App、亮屏都会在位置超过 30 分钟时自动重新定位（失败 5 分钟后重试），不用手动点。
1. 腾讯天气 `wis.qq.com`：位置在中国大陆时使用（中央气象台数据），含 7 天预报、逐小时降水、生活指数（穿衣/雨伞/紫外线/感冒…）、预警、空气质量
2. Open-Meteo：境外或腾讯不可用时使用，含未来 2 小时降水预报
- 经纬度 → 省市区：中国大陆优先用高德逆地理编码（可选，需自己申请「Web服务」Key，`Config.kt` 的 `AMAP_KEY` 是所有用户共用的公共接口（有频率限制），用户也可以在 App「设置 → 天气 → 天气接口」填自己的 Key），没填或失败时用内置离线区县表（assets/cn_districts.tsv，2890 个区县中心坐标，来源阿里云 DataV），不联网、不需要翻墙；港澳台和海外才用 BigDataCloud 联网查
- 手机定位完全失败时，用国内的 myip.ipip.net 按网络 IP 大致定位到城市（开着代理/VPN 会定位到代理所在地）
- 自动定位、城市搜索、生活建议

**按地区自动选线路**
- 自动判断顺序：出口 IP（Cloudflare → myip.ipip.net）→ 定位（反查国家码）→ SIM 卡 / 时区；结果缓存 6 小时，切换网络后重测。
- 以 IP 为先，是因为接口快慢取决于网络出口（例如人在大陆但开了境外代理，就该走境外节点）。
- 大陆：必应 `cn.bing.com`、一言 `v1.hitokoto.cn`；境外（含港澳台）：必应 `www.bing.com`（繁体界面用 zh-TW 地区）、一言 `international.v1.hitokoto.cn`。首选节点失败时自动换另一个。

**兼容性**
- Android 7.0（API 24）及以上；7.x 上用旧版接口（悬浮窗类型、解锁方式、无通知渠道、普通图标），`java.time` 通过脱糖库支持。
- 小米、华为、荣耀、OPPO / 一加 / realme、vivo / iQOO、三星、魅族都有对应的自启动、后台、电池设置入口；其他品牌引导到应用详情。
- 华为鸿蒙 HarmonyOS 2 / 3 / 4（兼容安卓应用）可用；**纯血鸿蒙 HarmonyOS NEXT / 5 及以上不能安装 APK**，需要用 ArkTS 另写一个鸿蒙原生版。

**其他**
- 界面主题：暗黑（默认，黑金配色）/ 白天 / 自动（6:00–18:00 白天，其余暗黑），在「设置 → 主题、壁纸与字体」切换；只影响 App 界面，锁屏颜色跟随壁纸。
- 语言只支持简体、繁體：默认跟随系统（繁体系统用繁體，其它用简体），可手动指定；纪年可选「民國」/「中華民國」，中文数字可选。
- 通知栏常驻民国日期 + 农历 + 天气。
- 一个 4×3 小组件：时间、民国日期、农历、天气、名言；背景始终透明无边框，可选白字 / 深色字；可拖动调整宽高（宽度最多到屏幕宽，高度 100–360dp），字号随大小缩放；点天气打开本应用天气页，点名言换一句。
- 长按桌面图标：「更换图标」（9 种：通用 5 种 + 简体 民国/纪年 + 繁體 民國/紀年）、「修改应用名称」（简体：民国纪年 / 民国时钟 / 民国数位时钟表；繁體：民國紀年 / 民國時鐘 / 民國數位時鐘錶），两者互相独立；直接修改桌面上的原图标，「关于」页的名称和图标跟着变。
- 首次打开会依次申请通知、位置（仅在使用中允许即可，建议开精确位置以使用 GPS）、悬浮窗、忽略电池优化；拒绝任何一项就退出，下次打开缺什么再要什么。
- 设置菜单：清空缓存、重置、检查更新、反馈、关于。
- 不在最近任务中显示；崩溃后自动重启，每 15 分钟自检。

## 编译

推到 GitHub 后 Actions 自动编译，一次出 10 个 APK（在该次运行页面的 Artifacts 里下载；推送 `v3.16.0` 这样的 tag 会自动发布到 Releases）：

| 文件 | 用途 |
|---|---|
| `MinguoClock-v3.16.0-universal-release.apk` | **不知道选哪个就用这个**，所有手机通用 |
| `…-arm64-v8a-release.apk` | 2017 年以后的绝大多数手机 |
| `…-armeabi-v7a-release.apk` | 老的 32 位手机 |
| `…-x86_64-release.apk` / `…-x86-release.apk` | 电脑上的安卓模拟器 |
| `…-*-debug.apk` | 调试版：名为「民国纪年 调试版」，包名多 `.debug`，可与正式版同时安装，用于排查问题 |

> 本应用没有 C/C++ 代码，各架构包内容相同，通用包在任何手机上都能装。

本地编译：`./gradlew assembleRelease assembleDebug`，产物在 `app/build/outputs/apk/`。

**签名**：默认用仓库里的 `keystore/minguo.jks`（密码 `minguo123`），每次编译签名一致，新版可直接覆盖安装。想换成自己的密钥，在仓库 Settings → Secrets and variables → Actions 里添加：
`KEYSTORE_BASE64`（`base64 -w0 你的.jks` 的结果）、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_ALIAS`、`SIGNING_KEY_PASSWORD`。注意换密钥后要先卸载旧版。

**鸿蒙**：HarmonyOS 2 / 3 / 4 直接装 APK 即可。纯血鸿蒙 HarmonyOS NEXT / 5+ 不能装 APK，需要另写 ArkTS 原生版（计划中），且安装包必须用华为开发者证书签名。

## 首次设置

1. 打开 App → 设置 → 权限检查：通用权限（悬浮窗、忽略电池优化、通知、位置）全部开启；再按下方「本机品牌」区块逐项点开确认（自启动、后台运行、锁屏显示等，各品牌名称不同）。
2. 设置 → 锁屏模式与密码：
   - 选「完全替代」→ 点「打开系统锁屏设置」把锁屏方式改成「无」→ 回来设置民国锁屏密码；
   - 或选「保留系统密码」。
3. 首页「编辑锁屏布局」：拖动元素、添加国旗等图片、点选元素改字体字号，点「保存」。
4. 天气：设置 → 天气，打开自动定位即可，不需要任何账号。

## 已知限制（如实说明）

- **不 root 无法删除系统锁屏**。完全替代模式依赖把系统锁屏设为「无」：此时系统会清除指纹/人脸；锁屏时下拉通知栏和控制中心仍然可用；安全性低于系统密码。
- **状态栏里系统自带的时间**无法修改；通知栏里用常驻通知显示民国日期。
- 完全替代模式是悬浮窗，状态栏图标颜色由系统决定，本应用只能尽力设置。
- 完全替代模式下，来电、闹钟响起时锁屏会自动让开，结束后（来电）重新锁上；闹钟、紧急呼叫之后要到下次熄屏才重新上锁。
- 在系统设置/手机管家里**强行停止**后，Android 会冻结一切自动恢复，需重新打开 App 或重启手机。
- 腾讯天气、BigDataCloud 都是免注册的公开接口，没有官方服务保证；如果某天不可用，会自动退回 Open-Meteo / 系统 Geocoder。
- Android 7.x 不支持「一键添加小组件到桌面」，需要长按桌面手动添加。
- 图标和名称用 54 个启动入口（9 图标 × 6 名称）实现，只能从内置图标和名称里选；系统设置的应用列表里仍显示默认名称。切换后部分桌面要几秒才刷新，图标位置可能会变。
- 锁屏/熄屏时的定位：锁屏服务以「定位」类型的前台服务运行，只给「仅在使用中允许」也能在后台定位。但系统只允许从前台启动这种服务：开机自启后要打开一次 App 才会生效（打开前用最近一次的位置）；给「始终允许」则不受此限制。
- 繁体名言用系统 ICU 自动简转繁（Android 10+），个别字可能不够准确。

## 文件结构

```
app/src/main/java/app/minguo/calendar/
├── MinguoApp.kt     崩溃自动重启、15 分钟自检
├── MainActivity.kt  首页 + 设置菜单（缓存/重置/更新/反馈/关于）
├── LockActivity.kt  保留系统密码模式锁屏、预览、编辑布局；紧急呼叫/相机
├── LockOverlay.kt   完全替代模式的悬浮窗锁屏
├── LockContent.kt   锁屏界面：可拖动元素、贴图、跑马灯签名、编辑面板、密码键盘
├── LockService.kt   熄屏上锁、来电/闹钟让路、通知栏民国日期
├── LockLayout.kt    元素位置/字号/字体/贴图的保存
├── Fonts.kt         系统字体 + 内置字体（assets/fonts）+ 导入 TTF/OTF
├── Quotes.kt        名言（内置 + 一言混合，30 分钟一换）
├── Weather.kt       腾讯天气 + Open-Meteo、定位、建议
├── Wallpaper.kt     自选图片、必应壁纸（按屏幕选分辨率）
├── Widgets.kt       桌面小组件（一个，含时间/日期/天气/名言）
├── IconSwitcher.kt  图标、名称各自切换（18 个启动别名）、长按图标菜单
├── IconPickerActivity.kt  更换图标 / 修改名称页面
├── PermissionGate.kt 启动时权限检查（拒绝即退出）
├── Region.kt        判断大陆 / 境外（IP → 定位 → SIM/时区），选择必应和一言节点
├── Geo.kt           经纬度 → 国家 / 省 / 市 / 区（BigDataCloud 免注册）
├── Brand.kt         品牌 / 鸿蒙识别，各品牌后台设置入口
├── Security.kt      锁屏密码（加盐哈希）
├── Maintenance.kt   清缓存、重置、检查更新、反馈
├── RocCalendar.kt   民国/中华民国纪年、农历
├── AppTheme.kt      界面主题（暗黑 / 白天 / 自动）和配色
├── Lang.kt          语言
├── ClockUi.kt       背景、数字动画等通用组件
├── Prefs.kt / Config.kt / Net.kt / ClockThemes.kt / BootReceiver.kt
```
